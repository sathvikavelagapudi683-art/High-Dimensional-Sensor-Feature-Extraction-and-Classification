# High-Dimensional Sensor Feature Extraction & Classification

EEG P300 classification experiments using the INRIA BCI Challenge dataset, feature engineering, and grouped validation.

> **Reproducibility note:** This repository contains a documented implementation of the covariance/tangent-space workflow described in the project's methodology slides. The original `.npy` dataset files and exact original training notebook were not available in the project archive. The code here is a clean implementation of the documented method, not a byte-for-byte recovery of the original experiment. The historical metrics below are recorded separately and are not claimed to be regenerated by this code.

## Project overview

The project processed the INRIA BCI P300 dataset with the following reported data shape:

- 5,440 epochs
- 56 EEG channels
- 260 samples per epoch (1.3 seconds at 200 Hz)
- 16 participants in the source dataset
- Two target classes, with the recorded training-label distribution 3,850 / 1,590

The documented feature workflow converts multichannel epochs into covariance representations using xDAWN (three filters, SCM covariance estimator), maps covariance matrices into Riemannian tangent space, appends two session-level metadata columns (`Session` and `Feedback_Progress`), and standardizes the combined vectors using training-fold statistics only.

Three classifiers are compared using four-fold `GroupKFold` validation:

1. Elastic-net logistic regression (`C=0.03`)
2. RBF support-vector machine (`C=1.0`, `gamma=scale`)
3. Random forest (300 trees, minimum leaf size 5)

All classifiers use class balancing. Performance is computed from out-of-fold predictions.

## Setup

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Place the required files under `data/processed/` as described in [DATA_FORMAT.md](docs/DATA_FORMAT.md), then run:

```bash
python scripts/run_cv.py --data-dir data/processed --output-dir results/run
```

The script saves the aggregate metric table, fold-level metrics, and out-of-fold probabilities. It does not download the INRIA dataset automatically.

## Recorded results

Two distinct experiment snapshots are documented in [EXPERIMENTS.md](docs/EXPERIMENTS.md):

- The feature-engineering/classifier experiment highlighted in the project résumé recorded ROC-AUC **0.6704**, balanced accuracy **0.6271**, and macro-F1 **0.6114**.
- A separate covariance/tangent-space methodology deck recorded the three-model comparison in `results/methodology_deck_metrics.csv`; its RBF SVM ROC-AUC was **0.7079**.

These are separate runs with different documented experiment contexts. They must not be combined or presented as one model result.

## Limitations

- Raw EEG arrays, labels, group identifiers, and participant/session metadata are not included.
- The exact source notebook that generated the résumé-highlighted metrics was not recovered.
- Reproduction depends on the supplied `groups.npy` representing the intended independent unit. For subject-independent evaluation, groups should identify participants, not individual epochs.
- Results are experimental and are not a clinically validated BCI system.

See [REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md) before interpreting results.
